# 🧠 NeuroScan

An AI-powered web application for **brain tumor detection** using **U-Net with Attention Mechanism**. Upload MRI scans and get instant predictions for:
- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

---

## 🚀 Features

- 🔍 Deep learning-powered image segmentation (U-Net + Attention)
- 🧾 Classifies MRI scans into 4 categories
- 📁 Upload MRI images and view predictions instantly
- 🌐 Modern, responsive web UI
- 🔐 Authentication and secure image handling

---

## 🛠️ Tech Stack

### 💡 Machine Learning
- Python
- TensorFlow / Keras
- U-Net with Attention

### 🖥️ Web Frontend
- React
- Tailwind CSS / Styled Components

### 🔙 Backend
- Node.js + Express
- Python Flask API (for model inference)
